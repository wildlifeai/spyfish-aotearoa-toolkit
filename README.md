# Spyfish Aotearoa Pipeline

Work in Progress, we are making the pipeline more robust, so things are changing often.
Check back in July 2026 for more info on our pipeline and how to contribute.

Automated pipeline for processing marine Baited Underwater Video (BUV) data: metadata ingestion, ML inference, Zooniverse citizen science, BIIGLE expert annotation and dashboard visualisation.

Check out our [CitSci platform](https://www.zooniverse.org/projects/victorav/spyfish-aotearoa) for more info about the project, our [project website](https://wildlife.ai/projects/spyfish-aotearoa/) for updates and our [wiki](https://spyfish.notion.site/overview) for tutorials and contributor information.

See ARCHITECTURE.md and the design_doc.md for full documentation: setup, architecture, CLI reference, configuration, module reference, and legacy data retrieval.

Reach out if you have any questions, ideas, feedback or if you want to contribute.
